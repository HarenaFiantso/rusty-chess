## What is Rusty Chess?

**Rusty Chess** is a modular, high-performance chess engine written in Rust. It is not just a single engine, it’s a **full ecosystem** including: **core engine** with bitboards, **search + evaluation engine**, **UCI interface**, **desktop GUI**, **bot + data pipeline**, and **machine learning pipeline (NNUE + MCTS)**.

Built to explore **clean architecture, performance, and modern Rust patterns**.
